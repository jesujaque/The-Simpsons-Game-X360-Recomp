# Código de conducta

## Nuestro compromiso

Como miembros y colaboradores, nos comprometemos a que la participación en este proyecto sea una
experiencia libre de acoso para todos, independientemente de edad, identidad de género, orientación
sexual, discapacidad, etnia, nivel de experiencia o religión.

## Comportamiento esperado

- Usar lenguaje acogedor e inclusivo.
- Respetar puntos de vista y experiencias distintas.
- Aceptar críticas constructivas con elegancia.
- Centrarse en lo que es mejor para el proyecto.
- Mostrar empatía hacia otros miembros.

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas.
- Comentarios insultantes, despectivos o ataques personales.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.
- Compartir o pedir enlaces a contenido pirateado.

## Aplicación

Los mantenedores pueden eliminar, editar o rechazar comentarios, commits, código e issues que no
cumplan este código. Las infracciones graves pueden suponer la expulsión del proyecto.

Para reportar un problema, abre un issue privado o contacta con el mantenedor.
