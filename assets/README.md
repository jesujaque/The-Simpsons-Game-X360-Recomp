# Assets propios del port

Aquí van **solo** recursos creados por el proyecto: iconos, logo del launcher, fuentes libres,
plantillas de UI y sonidos de interfaz.

No se suben texturas, modelos, audio, vídeo ni scripts extraídos del juego. Esos datos se instalan
desde la copia del usuario en `game/extracted/` (ignorado por git).

## Convenciones

- Formatos: PNG/WebP para imágenes, OGG para audio de UI, TTF/OTF con licencia compatible.
- Nombres en `kebab-case`: `launcher-icon.png`, `logo-dark.webp`.
- Incluye la licencia de cada recurso de terceros en `assets/LICENSES.md`.
