# Fase 6 — Mejoras de port

> **Estado:** continuo.

## Alcance

Mejoras que no bloquean la campaña pero acercan el port a un juego de PC:
framerate, aspect ratio, accesibilidad y renderer nativo progresivo.

## Tareas abiertas

- [ ] 60 FPS con lógica a velocidad original (timestep fijo).
- [ ] Ultrawide y FOV ajustable.
- [ ] Escalado de resolución, AA y filtrado anisotrópico.
- [ ] Skipping de logos, selector de episodios.
- [ ] Accesibilidad: subtítulos, tamaño de UI, remapeo completo.
- [ ] Renderer nativo progresivo (sustituir rutas de Xenos).

## Criterio de salida

No hay un cierre único: cada mejora entra por PR con su propia prueba y
documentación.
